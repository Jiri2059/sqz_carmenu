# Features
- ESX/QBCore support
- Choose from 3 menus
- Choose from 6 types of notifications
- Enable/disable menu items
- Cruise Control
- Speed Limiter
- Vehicle extras
- Turn on/off engine
- Open close vehicle parts
- Windows control
- Turn off/on neons
- Manage liveries
- Turn off/on lights

## Requirements
- ox_lib (https://github.com/overextended/ox_lib/releases)

## Instalation
 1) Put it into your FiveM resources folder
 2) Put `ensure sqz_carmenu` to your server.cfg or whatever you use
 3) Edit in Config file everything you want
